# Heart Failure Readmission Prediction Backend

Production-ready FastAPI backend for predicting 30-day readmission in heart failure patients.

## Tech Stack
- **FastAPI**: REST API framework
- **XGBoost**: Trained predictive model
- **SHAP**: Local feature explainability
- **Google Gemini API**: Clinical interpretation & recommendations
- **Supabase**: PostgreSQL Database & Auth (JWT verification)
